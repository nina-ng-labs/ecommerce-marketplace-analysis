# E-commerce Marketplace Analysis

## Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset by Olist to evaluate marketplace performance, customer purchasing behavior, seller performance and product category growth.

The analysis aims to answer key business questions using SQL and Power BI.

---

## Business Problem

Olist is a Brazilian e-commerce marketplace connecting customers and independent sellers.

The business wants to better understand marketplace performance by analyzing:

- Gross Merchandise Value (GMV)
- Customer purchasing behavior
- Seller contribution
- Product category performance
- Customer retention
- Delivery performance
- Payment behavior

The goal is to generate actionable insights and business recommendations to support marketplace growth.

---

## Business Questions

1. How has marketplace GMV changed over time?

2. Which product categories generate the highest revenue?

3. Which sellers contribute the highest GMV?

4. How concentrated is seller revenue?

5. What is the Average Order Value (AOV)?

6. What percentage of customers become repeat buyers?

7. Which categories are growing the fastest?

8. Does delivery speed affect customer review scores?

9. Which payment methods are most frequently used?

10. What recommendations can improve marketplace growth?
